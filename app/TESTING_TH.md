# คู่มือทดสอบ VAT Copilot บนโน้ตบุ๊ก (รอบ feedback แรก)

ทำตามลำดับ: **A ติดตั้ง (ครั้งเดียว) → B เปิดระบบ → C ลองตามสถานการณ์ → D จดผลส่งกลับ**

---

## A. ติดตั้งครั้งแรก (ครั้งเดียว ใช้เวลาราว 30–40 นาที ส่วนใหญ่คือรอดาวน์โหลด)

### A1. ลงโปรแกรม
ติดตั้งให้ครบ 4 ตัว (กด Next ตามค่าเริ่มต้นได้ทั้งหมด):

| โปรแกรม | ดาวน์โหลด | หมายเหตุ |
|---|---|---|
| Python 3.12 | https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe | ใช้ไฟล์ .exe นี้ **ไม่ใช่ "Python Install Manager"** (เครื่องที่ปิด sideloading จะติดตั้งตัวนั้นไม่ได้) หน้าแรกให้ติ๊ก **"Add python.exe to PATH"** ถ้าไม่มีสิทธิ์ admin ให้เอาติ๊ก "Use admin privileges" ออก |
| Node.js 20 LTS | nodejs.org | |
| Git | git-scm.com | |
| Ollama | ollama.com/download | |

### A2. ดาวน์โหลดโมเดล และตั้งค่า Ollama
เปิดหน้าต่าง **Command Prompt** (กด Start พิมพ์ `cmd`) แล้วพิมพ์ทีละบรรทัด:

```bat
ollama pull qwen2.5:3b-instruct
ollama pull nomic-embed-text
setx OLLAMA_MAX_LOADED_MODELS 2
setx OLLAMA_NUM_PARALLEL 1
```

จากนั้นปิด Ollama ที่มุมขวาล่าง (คลิกขวาไอคอนรูปลามะแล้วเลือก Quit) แล้ว**เปิด Ollama กลับจากเมนู Start** เพื่อให้ค่าที่ตั้งไว้มีผล
ตรวจว่าเปิดแล้วด้วย `ollama list` ต้องเห็นทั้ง `qwen2.5:3b-instruct` และ `nomic-embed-text`

> ขั้น A3 ต้องเปิด Ollama ค้างไว้ ถ้าไม่เปิดจะขึ้น error `WinError 10061`

### A3. ดาวน์โหลดโค้ด และเตรียม backend
เปิด Command Prompt **หน้าต่างใหม่** (ค่า setx จะมีผลเฉพาะหน้าต่างที่เปิดหลังจากตั้ง):

```bat
cd %USERPROFILE%\Documents
git clone -b app-fixes https://github.com/Pp370493/vat-chatbot.git
cd vat-chatbot\app\backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
copy .env.example .env
venv\Scripts\python scripts\setup_db.py --ingest
```

คำสั่งสุดท้ายจะแสดงรหัสผ่านของ 3 บัญชีบนจอ **แสดงครั้งเดียว ให้ถ่ายรูปหรือจดไว้:**

```
officer         officer@rd.go.th       ........
senior_officer  supervisor@rd.go.th    ........
admin           admin@rd.go.th         ........
```

ถ้าต้องการตั้งรหัสเอง ใช้ `--password-officer xxx --password-senior yyy --password-admin zzz`

### A4. เตรียมหน้าเว็บ

```bat
cd ..\frontend
npm ci
npm run build
```

## B. เปิดระบบ (ทำทุกครั้งที่จะทดสอบ)

1. ดับเบิลคลิกไฟล์ `vat-chatbot\app\START_VAT_COPILOT.bat` ระบบจะเปิดหน้าต่างย่อ 3 หน้าต่าง (Ollama, Backend, Frontend) แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:3000 ให้เอง
2. ถ้าเบราว์เซอร์ขึ้นว่าเปิดไม่ได้ ให้รอ 10–20 วินาทีแล้วกด Refresh
3. **ขณะทดสอบ ห้ามปิดหน้าต่างย่อทั้ง 3** ทดสอบเสร็จแล้วค่อยปิด

**เวลาที่ต้องรอ (บนเครื่อง i5-8250U / RAM 8 GB):**
- คำถามแรกหลังเปิดเครื่องช้ากว่าปกติ เพราะต้องโหลดโมเดลเข้า RAM
- คำถามปกติใช้ราว **1.5–2 นาทีต่อข้อ** ระหว่างนี้ไม่ต้องกดซ้ำ
- เคสเสี่ยงและคำถามนอกสโคปควรตอบภายในไม่กี่วินาที
- ปิดโปรแกรมอื่นที่กิน RAM มาก (เช่น Chrome หลายแท็บ, Teams) จะช่วยให้เร็วขึ้น

## C. สถานการณ์ทดสอบ

คัดลอกคำถามไปวางในช่องแชทได้เลย หรือจะพิมพ์คำถามของตัวเองเพิ่มก็ได้ (ยิ่งเป็นเคสจริงยิ่งดี)

### เข้าระบบเป็นเจ้าหน้าที่: `officer@rd.go.th`

| ข้อ | ลองทำ | ผลที่ควรได้ |
|---|---|---|
| 1 | คำถามปกติ: **"ธุรกิจขายพืชผลการเกษตรซึ่งยกเว้น VAT แต่อยากจด VAT เพื่อเคลมภาษีซื้อ ทำได้ไหม"** | ได้คำตอบพร้อมอ้างอิงประกาศฉบับที่ 57 หรือ 159 |
| 2 | คำถามที่ไม่ระบุช่องทาง: **"ต้องใช้เอกสารอะไรบ้างในการจด VAT"** | ระบบถามกลับว่ายื่นช่องทางไหน เมื่อกดปุ่ม "กระดาษ" หรือ "อินเทอร์เน็ต" ต้องได้คำตอบเรื่อง**เอกสาร**ของช่องทางนั้น ไม่ใช่คำตอบเรื่องอื่น |
| 3 | เคสเสี่ยง: **"สำนักงานบัญชีที่รับทำบัญชีให้บอกว่า ให้ใช้ที่อยู่สำนักงานบัญชีของเขาจด VAT ไปก่อนได้ แบบนี้สรรพากรจะยอมออกใบ ภ.พ.20 ให้ไหมครับ"** | ขึ้นภายในไม่กี่วินาทีว่าส่งให้หัวหน้างานพิจารณา |
| 4 | เคสเสี่ยง: **"เคยโดนเพิกถอนแวทเพราะมีปัญหากับเขต ต้องรอกี่ปีถึงจะกลับมาขอจด ภ.พ.20 ใหม่ได้ครับ"** | ส่งให้หัวหน้างานพิจารณาเช่นเดียวกับข้อ 3 |
| 5 | นอกสโคป: **"ย้ายสาขาจากห้างหนึ่งไปอีกห้างหนึ่ง ต้องแจ้ง ภ.พ.09 ล่วงหน้ากี่วัน"** | แจ้งว่าไม่ใช่เรื่องจดทะเบียน และแนะนำหน่วยงานที่ดูแลเรื่องนี้ |
| 6 | นอกสโคป: **"ค่ารับรองลูกค้า หักเป็นรายจ่ายทางภาษีได้ไม่เกินกี่เปอร์เซ็นต์ของยอดขาย"** | เหมือนข้อ 5 |
| 7 | ข้อมูลส่วนตัว: ถามคำถามที่มีเลขบัตรประชาชน 13 หลักหรือเบอร์โทรปน เช่น "ลูกค้าเลขบัตร 1234567890123 โทร 0812345678 ต้องจด VAT ไหม ถ้ารายได้ 2 ล้านต่อปี" | ระบบยังตอบได้ตามปกติ (ฝั่งระบบจะตัดเลขเหล่านี้ออกก่อนบันทึก) |
| 8 | พิมพ์ในช่อง URL ว่า `localhost:3000/review` และ `localhost:3000/dashboard` | ต้องเข้าไม่ได้ เพราะเจ้าหน้าที่ไม่มีสิทธิ์ |

### ออกจากระบบ แล้วเข้าเป็นหัวหน้างาน: `supervisor@rd.go.th`

| ข้อ | ลองทำ | ผลที่ควรได้ |
|---|---|---|
| 9 | เปิดหน้า "ตรวจสอบ" (/review) | เห็นเคสจากข้อ 3 และ 4 ในคิว แต่ละเคสมีคำถามที่สรุปแล้ว จุดที่ขัดกับข้อ 6 ของประกาศ (พร้อมตัวบท) และร่างคำตอบเบื้องต้น |
| 10 | แก้ไขร่างคำตอบของเคสหนึ่ง แล้วกดอนุมัติ ส่วนอีกเคสกดส่งกลับ (ไม่อนุมัติ) | บันทึกสำเร็จ และเคสหายออกจากคิวที่รอ |

### ออกจากระบบ แล้วเข้าเป็นผู้ดูแลระบบ: `admin@rd.go.th`

| ข้อ | ลองทำ | ผลที่ควรได้ |
|---|---|---|
| 11 | เปิดหน้า Dashboard | จำนวนคำถาม เคสเสี่ยง และนอกสโคป ต้องตรงกับที่ลองมาในข้อ 1–7 |
| 12 | เลื่อนดู Audit Log | มีรายการเข้าระบบ ออกจากระบบ และการตัดสินของหัวหน้างาน |

### ความปลอดภัยทั่วไป

| ข้อ | ลองทำ | ผลที่ควรได้ |
|---|---|---|
| 13 | ออกจากระบบ แล้วกดปุ่มย้อนกลับของเบราว์เซอร์ | ถูกพากลับไปหน้าเข้าสู่ระบบ ไม่เห็นข้อมูลเดิม |
| 14 | เข้าระบบด้วยรหัสผ่านผิด | ขึ้นข้อความว่าอีเมลหรือรหัสผ่านไม่ถูกต้อง |

## D. จดผลและส่ง feedback

กรอกตารางนี้ (หรือพิมพ์สั้นๆ ในแชทก็ได้) แนบภาพหน้าจอเมื่อผลไม่ตรงหรือดูแปลก

| ข้อ | ผลตรงไหม (✓/✗) | รอนานเท่าไร | เนื้อหาคำตอบถูกต้องไหม / ผิดตรงไหน | ความเห็นเรื่องหน้าจอ ความสะดวกในการใช้ |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| … | | | | |

**สิ่งที่อยากได้ความเห็นเป็นพิเศษ**
- คำตอบของข้อ 1, 2 ถูกต้องตามตัวบทไหม อ้างอิงฉบับที่ถูกต้องไหม
- สรุปเคสในหน้าหัวหน้างาน (ข้อ 9) ใช้ตัดสินใจได้จริงไหม ขาดข้อมูลอะไร
- เวลาที่รอรับได้ไหม
- ข้อความหรือปุ่มตรงไหนไม่ชัด หรือควรเปลี่ยนคำ

> ทราบอยู่แล้ว (ยังไม่ต้องรายงานซ้ำ): โมเดล 3B ยังตอบบางเคสคลาดเคลื่อน เช่น บอกว่าคอนโดยื่นที่สาขาได้ หรือบอกให้ใช้สำเนาบัตรประชาชน
> และ Agent 1 ยังจัดกลุ่มคำถามผิดราว 3 ใน 24 ข้อ ทั้งสองเรื่องรอข้อมูลเคสชุดใหม่

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `WinError 10061` / `actively refused it` / "เชื่อมต่อ Ollama ไม่ได้" ตอนรัน setup_db | Ollama ไม่ได้เปิด ให้เปิดจากเมนู Start (ต้องมีไอคอนลามะที่มุมขวาล่าง) แล้วรันคำสั่งเดิมใหม่ ข้อมูลไม่เสียหาย |
| `npm.ps1 cannot be loaded because running scripts is disabled` | เกิดใน PowerShell ให้พิมพ์ `npm.cmd ci` และ `npm.cmd run build` แทน หรือใช้หน้าต่าง Command Prompt (cmd) |
| หน้าเว็บขึ้น "เชื่อมต่อระบบไม่ได้" | หน้าต่าง Backend ปิดอยู่หรือ error ให้เปิดหน้าต่าง "VAT Backend" ดูข้อความ แล้วส่งภาพมา |
| รอคำตอบนานเกิน 5 นาที | Ollama ไม่ได้เปิด หรือ RAM เต็ม ให้ปิดโปรแกรมอื่นแล้วลองใหม่ |
| `python` หรือ `npm` ไม่รู้จักคำสั่ง | ตอนติดตั้งไม่ได้ติ๊ก Add to PATH หรือยังไม่ได้เปิด Command Prompt ใหม่ ให้ปิดแล้วเปิดใหม่ หรือติดตั้งใหม่แล้วติ๊กให้ถูก |
| หน้าเว็บไม่ขึ้นเลย | ยังไม่ได้ทำ `npm run build` ในข้อ A4 |
| ลืมรหัสผ่าน | ในโฟลเดอร์ `app\backend` สั่ง `venv\Scripts\python scripts\setup_db.py --reset-passwords` ระบบจะสุ่มรหัสใหม่ให้ |
| อยากล้างข้อมูลทดสอบเริ่มใหม่ | ปิดระบบ ลบไฟล์ `app\backend\vat_copilot.db` แล้วทำคำสั่งสุดท้ายของข้อ A3 ใหม่ |

ติดตรงไหน ให้ถ่ายภาพหน้าต่างที่มีข้อความ error ส่งมาในแชทได้เลย
