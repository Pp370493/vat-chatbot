# VAT Chatbot (ฉบับทดลอง)

หน้าเว็บถามตอบเรื่องการจดทะเบียนภาษีมูลค่าเพิ่ม ทำงานดังนี้
1. คำถามถูกค้นในฐานความรู้ (`data/`) ด้วยตัวค้นหลายระดับ และแนบมาตราที่ต้องอ้างเรื่องโทษเมื่อเกี่ยวข้อง
2. ข้อมูลที่ค้นได้ส่งให้โมเดลใน Ollama ตอบ โดยคำสั่งระบบ (`system_prompt.md`) บังคับให้ตอบจากข้อมูลอ้างอิงเท่านั้น
3. ระบบทำงานในเครื่อง ไม่ส่งคำถามออกอินเทอร์เน็ต

> ฉบับทดลอง ยังไม่ผ่านการตรวจของผู้เชี่ยวชาญ และไม่ใช่คำแนะนำทางกฎหมาย

## สิ่งที่ต้องมี
- Python 3.12 (ติดตั้งจาก python.org และติ๊ก Add python.exe to PATH)
- Ollama สำหรับ Windows (https://ollama.com/download) เปิดแอปค้างไว้ขณะใช้งาน
- ข้อมูลและโมเดล (ทำตามขั้นตอนด้านล่าง)
- Visual C++ Redistributable 2015-2022 (x64) ติดตั้งแล้วจากขั้นตอนก่อนหน้า

## ขั้นตอน (Windows, cmd)

**1. ดึงโมเดลภาษาใน Ollama** (ครั้งเดียว)
```bash
ollama pull qwen2.5:3b
```

**2. ดาวน์โหลดโมเดลเวกเตอร์ e5** (จากโฟลเดอร์ราก repo)
```bash
python scripts\download_models.py
```

**3. สร้างและเปิดสภาพแวดล้อม** (จากโฟลเดอร์ราก repo)
```bash
python -m venv app\.venv
```
```bash
app\.venv\Scripts\activate
```

**4. ติดตั้งไลบรารี**
```bash
pip install -r app\requirements.txt
```

**5. รันทดสอบ** (ไม่ต้องมี Ollama ก็ทดสอบได้)
```bash
python -m unittest app\tests\test_app.py
```
ต้องขึ้น `OK`

**6. เปิดเว็บ**
```bash
python app\server.py
```
แล้วเปิดเบราว์เซอร์ไปที่ http://127.0.0.1:5000

## ตัวแปรสภาพแวดล้อม (ไม่บังคับ)
| ตัวแปร | ค่าเริ่มต้น | ใช้เมื่อ |
|---|---|---|
| `VAT_LLM_MODEL` | `qwen2.5:3b` | ต้องการเปลี่ยนโมเดลภาษาใน Ollama |
| `VAT_OLLAMA_HOST` | `http://127.0.0.1:11434` | Ollama รันเครื่องอื่น |
| `VAT_E5_DIR` | `models\multilingual-e5-small-q8` | ย้ายโฟลเดอร์โมเดล |
| `VAT_DATA_DIR` | `data` | ใช้ชุดข้อมูลอื่น |
| `PORT` | `5000` | พอร์ตชนกับโปรแกรมอื่น |

## ข้อควรรู้
- โมเดล `qwen2.5:3b` เล็กและทำงานบน CPU ได้ แต่ภาษาไทยไม่แม่นเท่าโมเดลขนาดใหญ่ ถ้าเครื่องแรงขึ้นลอง `VAT_LLM_MODEL` ตัวอื่น
- ถ้า Ollama ไม่ได้เปิด หน้าเว็บยังแสดงข้อมูลอ้างอิงที่ค้นพบได้ และแจ้งว่าโมเดลตอบไม่ได้
- ครั้งแรกที่ถาม ระบบจะโหลดโมเดลเวกเตอร์ก่อน อาจใช้เวลาประมาณหนึ่งนาที
- เครื่อง RAM 8 GB ควรปิดโปรแกรมอื่นระหว่างใช้งาน
