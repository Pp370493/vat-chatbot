## ข้อควรรู้เมื่อนำเข้าโปรเจกต์
1. **ใช้ `is_current` กรองฉบับ:** ชิ้นที่ `is_current = false` คือฉบับที่ถูกแก้หรือยกเลิกแล้ว ไม่ควรใช้เป็นคำตอบหลัก (ตัวค้นเดิมให้น้ำหนักต่ำอยู่แล้ว)
2. **เวกเตอร์ต้องตรงกับ embedder:** เวกเตอร์ e5 ใช้ prefix `passage: ` ตอนสร้าง และ `query: ` ตอนค้น ถ้าเปลี่ยนโมเดลต้องสร้างดัชนีใหม่ทั้งชุด ห้ามผสม
3. **ชุดที่ใช้ค้นจริงคือ L1 (137 ชิ้น)** ส่วน L0 ใช้เฉพาะตอนจับข้อย่อยที่ตรงคำถาม L2/L3 ใช้เป็นบริบทเสริม
4. **ตัวชี้โทษไม่ใช่ตัวบท:** `reference_pointers.json` บอกว่าต้องอ้างมาตราใด ห้ามนำข้อความจากตัวชี้ไปเป็นอัตราโทษ
5. **ตัวบทที่ผู้ใช้วางเอง** (ม.77/2, 86–87/3, 83, 89, 89/1, 90, 90/2) ยังไม่ได้เทียบกับราชกิจจานุเบกษาปัจจุบัน
6. **ขนาด:** โมเดล e5 ประมาณ 118 MB ไม่ควร commit ตรงๆ ใช้ Git LFS หรือสคริปต์ดาวน์โหลด

## ลำดับนำเข้าที่แนะนำ
1. แตก `โมเดล_e5.zip` ให้ได้โฟลเดอร์ `โมเดล_e5`
2. โหลด `data/chunks_*.json` หรือ `data/units.jsonl` เข้าฐานข้อมูลของแอป (กรอง `is_current` ตามที่ต้องการ)
3. ถ้าใช้เวกเตอร์ ให้โหลด `embeddings/multilingual-e5-small-q8/L*.npy` คู่กับ `ids_L*.json` ตามลำดับเดียวกัน
4. ทดสอบคำถามจาก `ชุดทดสอบ_เก็บเป็นส่วนตัว` ที่ไม่มีเฉลยก่อน แล้วค่อยใช้ชุดที่มีเฉลยวัดผล

ไฟล์ตรวจสอบความครบถ้วน: `SHA256SUMS.txt` (รันคำสั่ง `sha256sum -c SHA256SUMS.txt` ในโฟลเดอร์นี้)
